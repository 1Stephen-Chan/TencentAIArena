## 动作后处理

### 问题
模型可能连续做矛盾的动作（如右-左-右），导致"抖动"现象。

### 解决方案
对模型输出的动作概率做加权平滑：

```python
def smooth_action(action_probs, prev_action, smoothing=0.7):
    """惩罚方向变化过大的动作"""
    if prev_action is not None:
        # 如果当前动作和上一步方向相反，降低其概率
        if is_opposite_direction(action_probs, prev_action):
            action_probs = action_probs * (1 - smoothing)
            action_probs = action_probs / action_probs.sum()
    return action_probs
```

### 预期效果
- 防止"抖动"动作，提高生存稳定性
- 平滑的动作在迷宫里更容易找到出路

### 难度
**低** - 纯后处理，无需改网络

## 危险区域感知

### 问题
模型可能走进死角才反应过来，缺乏前瞻性。

### 解决方案

#### 1. 死角检测
分析局部地图，标记出死角和短走廊位置：

```python
def detect_dead_ends(map_info, pos):
    """检测当前位置是否为死角"""
    directions = [(0, 1), (0, -1), (1, 0), (-1, 0), ...]
    escape_routes = 0

    for dx, dz in directions:
        nx, nz = pos.x + dx, pos.z + dz
        # 检查从(nx, nz)出发能走多远
        depth = trace_path_depth(map_info, nx, nz)
        if depth > 3:  # 能走3步以上不算死角
            escape_routes += 1

    return escape_routes < 2  # 只有1条逃生路就是死角
```

#### 2. 加入特征
- `is_dead_end`：当前位置是否为死角
- `min_escape_depth`：周围各方向能走的最深距离
- `is_corridor`：是否在走廊中

#### 3. 加入奖励
- 进入死角区域时给惩罚

### 预期效果
让模型提前知道哪些方向是危险的，避免走进死角。

### 难度
**低** - 主要改特征工程

## 时序建模

### 问题
特征只考虑当前帧，模型无法知道：
- 最近几步是不是在绕圈
- 怪物是否连续逼近（被追的趋势）
- 上几步做了什么

### 解决方案
在网络中加入 RNN 层（LSTM/GRU）：

```python
class Model(nn.Module):
    def __init__(self):
        # ... backbone ...
        self.rnn = nn.GRU(hidden_dim, hidden_dim, batch_first=True)

    def forward(self, obs_seq):
        # obs_seq: (batch, seq_len, feature_dim)
        rnn_out, _ = self.rnn(obs_seq)
        # 使用最后一步的输出
        hidden = rnn_out[:, -1, :]
        logits = self.actor_head(hidden)
        value = self.critic_head(hidden)
        return logits, value
```

### 需要修改的地方
1. `preprocessor.py`：保留最近 N 步的特征序列
2. `model.py`：加入 RNN 层
3. `SampleData`：存储历史序列

### 预期效果
- 识别"绕圈"模式
- 识别"被追"的趋势
- 学习时序模式辅助决策

### 难度
**中** - 需要改网络结构和数据流

## 探索增强

### 问题
模型可能只探索地图的一部分，陷入局部最优。

### 解决方案

#### 1. 熵奖励（Entropy Bonus）
```python
entropy_bonus = config.entropy_coef * action_entropy
total_loss = policy_loss - entropy_bonus
```

#### 2. Epsilon-Greedy 探索
```python
if random.random() < epsilon:
    action = random.choice(range(action_num))
else:
    action = model(obs).argmax()
```

#### 3. 奖励塑形
- 探索新区域时给额外奖励
- 惩罚重复访问相同位置

### 预期效果
- 鼓励探索新区域
- 避免过早收敛到次优策略

### 难度
**中** - 主要需要调参

## Prioritized Experience Replay

### 问题
当前 PPO 采样是均匀的，但某些样本比其他更重要。

### 解决方案
根据 TD 误差或 reward 大小来加权采样：

```python
def compute_priority(sample):
    """计算样本优先级"""
    td_error = abs(sample.reward + config.gamma * sample.next_value - sample.value)
    return td_error ** config.alpha  # alpha 控制优先级权重

def sample_with_priority(samples, config):
    priorities = [compute_priority(s) for s in samples]
    probs = np.array(priorities) ** config.alpha
    probs = probs / probs.sum()
    indices = np.random.choice(len(samples), size=config.batch_size, p=probs)
    return [samples[i] for i in indices]
```

### 需要修改的地方
- `workflow/train_workflow.py`：实现加权采样

### 预期效果
- 优先学习高价值样本（如"差点死掉"的样本）
- 提高样本效率

### 难度
**高** - 实现复杂，效果不确定
