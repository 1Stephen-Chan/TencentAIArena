# 开发计划总结

## 一、已完成的代码实现

### 1. agent_diy/feature/preprocessor.py ✅
**核心功能**：特征提取 + 奖励计算

| 功能 | 实现情况 |
|------|---------|
| BFS 真实路径距离 | ✅ 视野内 BFS，视野外离散桶兜底 |
| 16维合法动作掩码 | ✅ 支持 8移动 + 8闪现 |
| 闪现相关参数 | ✅ flash_cooldown, flash_count |
| Buff 刷新时间 | ⚠️ 通过 env_info 获取 |
| 物件类型区分 | ✅ sub_type=1 宝箱，sub_type=2 buff |
| 地形特征 | ✅ 8方向通路深度 + 死角 + 走廊 + 开阔 |
| 怪物视野标记 | ✅ is_in_view 区分视野内外 |
| 分阶段奖励 | ✅ 步数得分、宝箱得分、距离 shaping |

**特征向量维度**：68 维

### 2. agent_diy/conf/conf.py ✅
**核心配置**：

| 参数 | 值 | 说明 |
|------|-----|------|
| FEATURE_VECTOR_SHAPE | (68,) | 特征维度 |
| ACTION_SHAPE | (16,) | 动作维度（8移动+8闪现） |
| GAMMA | 0.995 | 折扣因子 |
| LAMDA | 0.95 | GAE 参数 |
| CLIP_PARAM | 0.2 | PPO 裁剪参数 |
| START_LR | 3e-4 | 初始学习率 |
| END_LR | 1e-5 | 最终学习率 |
| MAX_GRAD_NORM | 0.5 | 梯度裁剪 |

### 3. agent_diy/model/model.py ✅
**网络结构**：MLP 双头架构

```
输入(68) → 256 → ReLU → Dropout(0.1) → 128 → ReLU → 分支
                                                    ├── Actor头(128→16)  # 策略
                                                    └── Critic头(128→1)   # 价值
```

### 4. agent_diy/algorithm/algorithm.py ✅
**PPO 算法实现**：

- 策略损失：PPO Clip 目标
- 价值损失：Clipped Value Function Loss
- 熵正则化：鼓励探索
- 掩码 softmax：处理 16 维合法动作

### 5. agent_diy/agent.py ✅
**主类实现**：

- `observation_process()`: 观测处理
- `predict()`: 训练时随机采样
- `exploit()`: 评估时贪心选择
- `learn()`: 训练入口
- `save_model()` / `load_model()`: 模型保存加载
- `_run_model()`: 模型前向传播
- `_legal_sample()`: 合法动作采样

### 6. agent_diy/feature/definition.py ✅
**数据结构**：

- `ObsData`: 观测数据结构
- `ActData`: 动作数据结构
- `SampleData`: 训练样本数据结构（68维观测，16维动作）

## 三、待完善功能

### 1. 完整地图获取
**问题**：当前 `map_info` 只有局部视野（21×21），无法计算视野外的真实路径距离

**改进方向**：
- 如果环境能提供完整地图坐标，可用 A* 替代 BFS
- 或维护一个探索过的地图记忆

### 2. Curriculum Learning（课程学习）
**问题**：未根据地图难度动态调整

**改进方向**：
- 利用 `total_map`, `map_random` 参数
- 简单图 → 复杂图 渐进过渡

### 3. 时序特征
**问题**：未使用 `frame_no` / `finished_steps`

**改进方向**：
- 加入历史帧位置差异特征
- 速度估计（位置差分）

### 4. Buff 刷新提醒
**问题**：`buff_refresh_time` 未直接利用

**改进方向**：
- 在 buff 即将刷新时给予奖励提示

## 六、关键参数对照表

### 特征向量构成（68维）

| 起始位置 | 维度 | 内容 |
|---------|------|------|
| 0 | 6 | 英雄特征（位置×2、得分×2、闪现就绪、buff剩余时间） |
| 6 | 12 | 怪物1特征（距离×1、方向×1、速度×1、位置×2、视野标记×1） |
| 18 | 12 | 怪物2特征（同上） |
| 30 | 6 | 最近宝箱特征（距离×1、方向×1、位置×2、存在标记×2） |
| 36 | 6 | 最近buff特征（激活×1、剩余时间×1、方向×1、距离桶×1、位置×2） |
| 42 | 5 | 技能特征（冷却CD、就绪标记、距加速节点、闪现次数、第二怪物信号） |
| 47 | 11 | 地形特征（8方向深度、死角标记、走廊标记、开阔标记） |
| 58 | 6 | 进度特征（步数进度、是否已加速、危险等级、卡住次数、已收集宝箱、已获取buff） |
| 64 | 4 | 预留（用于未来扩展） |
| 68 | **总计68维** | |

### 奖励函数构成

| 奖励项 | 系数 | 说明 |
|-------|------|------|
| 基础步奖励 | 0.01 | 每步存活奖励 |
| 步数得分增量 | ×0.1 | 鼓励多步 |
| 宝箱得分增量 | ×1.0 | 主要驱动 |
| Buff获取 | +0.5 | 收集奖励 |
| 怪物距离增量 | ×0.1 | 生存 shaping |
| 加速节点临近 | ×0.05 | 过渡辅助 |
| 拉开距离奖励 | +0.2 | 后期保命 |
| 宝箱接近 shaping | ×0.5 | 引导拿分 |
