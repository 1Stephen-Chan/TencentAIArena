# 进阶优化方案：实时建图 + 怪物追踪 + 真实距离计算

## 背景问题

当前DIY版本的距离计算存在以下问题：

### 1. 视野内外距离不连续

| 情况 | 当前实现 | 问题 |
|------|---------|------|
| 视野内 | BFS路径距离 / 42 | 准确 |
| 视野外 | 欧几里得距离（clamp到1.0） | 可能跳跃 |

**具体例子**：
- 英雄在视野边缘（21步处），BFS距离 = 0.5
- 走一步脱离视野，瞬间变为 1.0
- 奖励跳跃 +0.5，可能导致学习不稳定

### 2. 视野外距离不准确

- 欧几里得距离 ≠ 真实路径距离（迷宫地图差异大）
- 怪物可能绕路，英雄直线距离和真实距离差距大

---

## 进阶方案架构

```
┌─────────────────────────────────────────────────────────────┐
│                      实时建图系统                            │
├─────────────────────────────────────────────────────────────┤
│  1. 局部地图拼接：每步探索新区域 → 累积全局可达地图              │
│  2. 怪物追踪：视野内记录位置 + 速度方向                        │
│  3. 怪物预测：视野外根据移动模型推算可能位置                    │
│  4. 路径规划：A*/BFS 在累积地图上计算真实路径距离               │
└─────────────────────────────────────────────────────────────┘
```

## 模块设计

### 1. MapMemory - 全局地图记忆

```python
class MapMemory:
    """维护累积的全局可达地图"""
    def __init__(self, map_size=128):
        self.grid = np.full((map_size, map_size), -1)  # -1=未知, 0=障碍, 1=可达
        self.explored = set()

    def update(self, hero_pos, local_map):
        """每步更新累积地图"""
        cx, cz = hero_pos
        half = len(local_map) // 2
        for i in range(len(local_map)):
            for j in range(len(local_map[0])):
                wx, wz = cx - half + i, cz - half + j
                if 0 <= wx < 128 and 0 <= wz < 128:
                    if self.grid[wx, wz] == -1:  # 未探索
                        self.grid[wx, wz] = local_map[i][j]
                        self.explored.add((wx, wz))

    def is_explored(self, x, z):
        """检查某点是否已探索"""
        return (x, z) in self.explored

    def get_reachable_neighbors(self, x, z):
        """获取某点的可达邻居（4方向）"""
        neighbors = []
        for dx, dz in [(0,1), (0,-1), (1,0), (-1,0)]:
            nx, nz = x + dx, z + dz
            if 0 <= nx < 128 and 0 <= nz < 128 and self.grid[nx, nz] == 1:
                neighbors.append((nx, nz))
        return neighbors
```

### 2. MonsterTracker - 怪物追踪与预测

```python
class MonsterTracker:
    """追踪怪物位置，视野外预测"""
    def __init__(self):
        self.last_positions = {}   # monster_id -> (pos, step_no)
        self.last_directions = {}  # monster_id -> direction

    def update(self, monsters, step_no):
        """视野内更新怪物状态"""
        for m in monsters:
            if m.get("is_in_view"):
                self.last_positions[m["monster_id"]] = (m["pos"].copy(), step_no)
                self.last_directions[m["monster_id"]] = m.get("hero_relative_direction")

    def predict_position(self, monster_id, step_no, speed=1):
        """视野外预测怪物当前位置"""
        if monster_id not in self.last_positions:
            return None

        last_pos, last_step = self.last_positions[monster_id]
        steps_diff = step_no - last_step

        # 简单预测：假设怪物朝英雄方向匀速移动
        # 实际实现需要更复杂的移动模型
        direction = self.last_directions.get(monster_id, 0)
        dx, dz = self._direction_to_delta(direction)

        predicted_x = last_pos["x"] + dx * speed * steps_diff
        predicted_z = last_pos["z"] + dz * speed * steps_diff

        return {"x": predicted_x, "z": predicted_z}

    def _direction_to_delta(self, direction):
        """方向枚举转坐标增量"""
        direction_map = {
            0: (0, 0),   # 重叠/无效
            1: (1, 0),   # 东
            2: (1, -1),  # 东北
            3: (0, -1),  # 北
            4: (-1, -1), # 西北
            5: (-1, 0),  # 西
            6: (-1, 1),  # 西南
            7: (0, 1),   # 南
            8: (1, 1),   # 东南
        }
        return direction_map.get(direction, (0, 0))
```

### 3. PathPlanner - 路径规划器

```python
class PathPlanner:
    """A* 路径规划"""
    def __init__(self, map_memory):
        self.map_memory = map_memory

    def astar(self, start, goal):
        """A* 计算最短路径"""
        from collections import deque

        start = (int(start["x"]), int(start["z"]))
        goal = (int(goal["x"]), int(goal["z"]))

        if not self.map_memory.is_explored(*start) or not self.map_memory.is_explored(*goal):
            return float('inf')

        open_set = deque([(start, 0)])
        came_from = {start: None}
        g_score = {start: 0}

        while open_set:
            current, _ = open_set.popleft()

            if current == goal:
                return g_score[current]

            for neighbor in self.map_memory.get_reachable_neighbors(*current):
                tentative_g = g_score[current] + 1

                if neighbor not in g_score or tentative_g < g_score[neighbor]:
                    g_score[neighbor] = tentative_g
                    f_score = tentative_g  # + heuristic(neighbor, goal)
                    open_set.append((neighbor, f_score))
                    came_from[neighbor] = current

        return float('inf')
```

### 4. UnifiedDistanceCalculator - 统一距离计算

```python
class UnifiedDistanceCalculator:
    """统一距离计算接口"""
    def __init__(self):
        self.map_memory = MapMemory()
        self.monster_tracker = MonsterTracker()
        self.path_planner = PathPlanner(self.map_memory)

    def update(self, hero_pos, local_map, monsters, step_no):
        """每步更新"""
        self.map_memory.update(hero_pos, local_map)
        self.monster_tracker.update(monsters, step_no)

    def compute_distance(self, hero_pos, target_pos, target_type="treasure"):
        """
        计算统一距离
        - 视野内：使用累积地图 + A* 计算真实路径
        - 视野外：使用怪物预测位置 + A*
        """
        # 检查是否可用A*
        if not self.map_memory.is_explored(int(target_pos["x"]), int(target_pos["z"])):
            # 目标位置未探索，回退到欧几里得距离
            return self._euclidean_distance(hero_pos, target_pos)

        path_dist = self.path_planner.astar(hero_pos, target_pos)

        if path_dist < float('inf'):
            return path_dist / 42.0  # 归一化
        else:
            # A*失败，回退到欧几里得
            return self._euclidean_distance(hero_pos, target_pos)

    def _euclidean_distance(self, pos1, pos2):
        """欧几里得距离（连续）"""
        dist = np.sqrt((pos1["x"] - pos2["x"])**2 + (pos2["z"] - pos2["z"])**2)
        return dist / (MAP_SIZE * 1.41)
```

## 方案对比

| 方案 | 视野内 | 视野外 | 复杂度 | 效果 |
|------|--------|--------|--------|------|
| **当前版本** | BFS(准) | 欧氏(连续但不准确) | 低 | 中等 |
| **实时建图** | A*(准) | A*(准) | 中 | 较好 |
| **实时建图+预测** | A*(准) | 预测+A*(较准) | 高 | 最好 |

---

## 实现优先级

1. **Phase 1 - 基础版（当前）**
   - 视野内BFS，视野外欧几里得（去掉clamp）
   - 验证基础效果

2. **Phase 2 - 地图记忆**
   - 加局部地图累积记忆
   - 视野内用累积地图+A*
   - 视野外仍用欧几里得

3. **Phase 3 - 怪物预测**
   - 加怪物追踪器
   - 视野外用预测位置+A*
   - 需要验证预测准确性

---

## 风险与挑战

| 风险 | 影响 | 缓解措施 |
|------|------|---------|
| 地图不完整 | A*可能找不到路径 | 回退到欧几里得 |
| 怪物预测不准 | 视野外距离错误 | 用置信度加权 |
| 内存占用 | 128×128地图存储 | 可用稀疏存储 |
| 计算开销 | A*每步调用多次 | 缓存+增量更新 |

---

## 何时使用

建议在以下情况下考虑实现：

1. 当前方案在视野外表现差（经常撞墙/走冤枉路）
2. 训练收敛后，视野外移动策略不佳
3. 有足够计算资源支持A*每步计算

## 替代简化方案

如果完整实现太复杂，可考虑：

**简化版：基于探索区域的局部A***

```python
def compute_distance_simple(self, hero_pos, target_pos, local_map):
    """只在局部地图计算，视野外用欧几里得"""
    # 尝试在局部地图BFS
    center = len(local_map) // 2
    hx = int(hero_pos["x"] - self.hero_center_x + center)
    hz = int(hero_pos["z"] - self.hero_center_z + center)
    tx = int(target_pos["x"] - self.hero_center_x + center)
    tz = int(target_pos["z"] - self.hero_center_z + center)

    if 0 <= tx < len(local_map) and 0 <= tz < len(local_map[0]) and local_map[tx][tz] != 0:
        bfs_dist = self._bfs((hx, hz), (tx, tz), local_map)
        if bfs_dist < float('inf'):
            return bfs_dist / 42.0

    # 回退到连续欧几里得（不clamp）
    return self._euclidean_distance(hero_pos, target_pos)
```

这样只需修改 `_compute_real_distance` 函数，保持代码简单。
